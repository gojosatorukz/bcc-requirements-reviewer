# Выгрузка указателя переплётчиков

Издательский архив публикует неизменяемый годовой указатель мастеров. В рамках этой поставки читателю доступна только одна версия указателя за 2025 год. Файл загружается в приложение вместе с выпуском, сетевых обращений при поиске нет.

Читатель вводит точный код карточки и нажимает «Найти». Сравнение выполняется с полным кодом, с учётом регистра. У каждого кода в выпуске одна карточка. Для найденного кода экран показывает ровно название мастерской и город, для неизвестного или пустого ввода — «Карточка не найдена». Повторный поиск показывает результат для последнего ввода.

| Код | Мастерская | Город |
| --- | --- | --- |
| BQ-17 | Корешок | Семей |
| LD-58 | Старый пресс | Тараз |

Если ввести LD-58, экран показывает «Старый пресс» и «Тараз». При следующем вводе ld-58 экран показывает «Карточка не найдена».
