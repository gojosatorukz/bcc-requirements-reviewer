# Перепроверка одной правки

26 ноября 2026 года рабочее приложение запустило GPT-6.2 Astra на [ТЗ о резерве продавца](../../eval/priority/merchant-reserve.md). В [полном отчёте](full.json) четыре замечания. Критический конфликт касается выплаты при точном равенстве сумм. Два существенных вопроса касаются распознавания повторного события и записи настройки через GET. Редакционное замечание D-04 указывает на разное написание фамилии автора в двух полях паспорта.

В новой версии изменена одна буква в строке 28. Аналитик выбрал только D-04. В [повторном отчёте](recheck.json) агент присвоил ему статус «устранено» и сослался на строки 23, 27 и 28. Другие три замечания в область этой проверки не входили.

| Запуск | Длительность по паспорту | Итог |
|---|---:|---|
| Полное ревью | 176,76 с | 24 записи реестра, 4 замечания |
| Адресная перепроверка | 10,83 с | 1 выбранное замечание, 1 подтверждённое исправление |

Это длительности двух конкретных запусков с разным объёмом работы. Бинарный SHA-256 файла `full.json` совпадает с `previous_report_sha256` в паспорте повторной проверки. Два отчёта сохранены в том виде, в котором их отдал локальный сервер.
