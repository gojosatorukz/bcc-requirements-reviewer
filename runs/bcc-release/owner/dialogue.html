Ответ 1

По какой дате в Алматы определять месяц расходов, если покупка совершена в одном месяце, а проведена в следующем?

Для покупок на стыке месяцев завели отдельный счётчик «Переходящие». Это точно.

Требуется уточнение

Ответ 2

На сколько изменится каждый из трёх счётчиков (январь, февраль и «Переходящие») сразу после проведения 1 февраля покупки на 4 000 ₸ от 31 января?

Когда месяц покупки и проведения по Алматы различается, после проведения вся сумма идёт только в «Переходящие». Январь и февраль по этой покупке остаются без изменений. Если оба события в одном месяце, вся сумма идёт только в обычный счётчик этого месяца. В «Переходящие» в этом случае ноль.

Правило готово для проверки

Согласованные условия

  • Если по времени Алматы покупка совершена в одном месяце и проведена в другом, при проведении вся сумма увеличивает только отдельный счётчик «Переходящие». Месячные счётчики не меняются.
  • Если по времени Алматы покупка совершена и проведена в одном месяце, при проведении вся сумма увеличивает только обычный счётчик этого месяца. Прирост счётчика «Переходящие» по этой покупке равен нулю.
