# Запрос дубликата квитанции

Оператор отправляет идентификатор операции в POST /receipts/copies. Если архив принял заявку, экран показывает дату постановки. Если архив занят, экран показывает причину и позволяет повторить запрос. Отказ архива не создаёт заявку.

## Тело ответа

| Поле | Значение |
| --- | --- |
| ticketRef | Только при HTTP 202, обязательно. При HTTP 503 поле отсутствует, обращения ещё нет |
| queuedAt | Время постановки принятой заявки в очередь |
| message | Причина отказа |

## Примеры

### HTTP 202 — архив принял заявку

```json
{"ticketRef":"T-082","queuedAt":"2026-11-17T12:00:00Z"}
```

### HTTP 503 — архив занят

```json
{"message":"Архив занят"}
```
