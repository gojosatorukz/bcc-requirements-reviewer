# Бронирование репетиционного зала

Администратор музыкальной школы получает заявку и видит, в какой зал придёт группа. Свободны два зала. Все участники приходят одновременно.

## Распределение

Заявку на 18 музыкантов или меньше система направляет в Малый зал. Если музыкантов больше 18, система направляет заявку в Большой зал.

## Приёмка бронирования

| Участников в заявке | Зал на экране администратора |
| --- | --- |
| 17 | Малый |
| 18 | Большой |
| 19 | Большой |

## Выдача пропуска

После бронирования API возвращает номер заявки и назначенный зал. В успешном ответе оба поля обязательны.

Пример успешного ответа для группы из 17 человек

```json
{"booking": "Q-17"}
```
