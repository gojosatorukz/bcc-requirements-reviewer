# Проверка исходного и текущего значений

Проверяем через форму публичного приложения две спецификации. Загружается только исходный Markdown. Документ студии совпадает с использованным при проверке интерфейса. Второй документ написан для этой проверки. Исходы фиксируем до изменения агента.

| Документ | После изменения по первой инструкции | По второй инструкции | Контроль без изменения |
|---|---|---|---|
| [Тубус студии печати](studio-pickup.md) | Северное окно первого чтения | Южное окно после переноса | Северное окно у обеих |
| [Экспорт субтитров](caption-export.md) | Deutsch при открытии | Español при завершении | English у обеих |

Требуются настоящий Cloudflare в паспорте, повторяемая программа, связь каждой стороны с цитатой её правила и отсутствие расхождения на контрольном входе. Порядок правил в отчёте свободный. Сохраняем исходные JSON и HTML, в том числе отказ модели.

## Что удалось проверить до подачи

Оба исходника были загружены через форму на Render. Gemini вернул HTTP 429. Cloudflare Workers AI, модель `@cf/openai/gpt-oss-120b`, завершил оба исходных ревью, назвал обе трактовки и вернул `unsupported` для вычисления. После обновления ядра повторные загрузки упёрлись в квоту Cloudflare. Свежий сквозной расчёт той же моделью остался непроверенным.

По каждому сохранённому исходному JSON локальная Astra построила исполняемую программу. На втором обращении она независимо прочитала исходы по ТЗ. Интерпретатор проверил основной пример и контроль. Исходные замечания и паспорт Cloudflare сохранены без правок, отдельный запуск указан в `execution_run`.

| ТЗ | Публичный прогон Cloudflare | Отдельный расчёт Astra | Без изменения |
|---|---|---|---|
| Студия печати | [До](https://razbor-tz.onrender.com/reports/studio-pickup/before.html#execution-D-01) · 185,8 с | [Северное или южное окно](https://razbor-tz.onrender.com/reports/studio-pickup/assisted.html#execution-D-01) · 23,77 с | Северное у обеих трактовок |
| Экспорт субтитров | [До](https://razbor-tz.onrender.com/reports/caption-export/before.html#execution-D-01) · 180,05 с | [Deutsch или Español](https://razbor-tz.onrender.com/reports/caption-export/assisted.html#execution-D-01) · 21,40 с | English у обеих трактовок |

Время в третьей колонке относится только к построению и проверке примера. Все файлы до и после лежат в [runs](runs). Команда `python3 -m eval.retained-values.verify` заново исполняет программы, сверяет отпечатки, исходы, строки правил и квитанции публичной формы.

После публикации оба JSON были импортированы через сайт в двух независимых сессиях при ширине 390 px. В каждом браузере открылись карточка D-01 и её контроль. В 21:56 по Астане сайт принимал новые ТЗ только для Gemini Flash-Lite. На третьем документе о просмотре слайдов Gemini достиг лимита. По ссылке в сообщении интерфейс проверил структуру того же текста (три строки, три блока). [Квитанция публичной формы](runs/gemini-site.json)
