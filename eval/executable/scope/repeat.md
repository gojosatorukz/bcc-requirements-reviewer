# Ответ при повторной постановке выписки в очередь

Мобильный клиент отправляет POST /statement-requests с идентификатором ранее принятой заявки. Сервер авторизовал клиента, а заявка с этим идентификатором уже находится в его очереди. Повторный POST сохраняет очередь без изменений и не запускает второе формирование. Клиент читает только HTTP-статус и сохраняет уже показанный номер заявки.

## Протокол сервера

Для первого запроса с новым идентификатором сервер создаёт запись и возвращает HTTP 202. На повторный запрос с тем же идентификатором, пока запись в очереди, сервер возвращает HTTP 200; тело пустое.

## Приёмка мобильного интерфейса

| Исходное состояние | Действие | Ожидаемый HTTP-статус | Результат для очереди |
| --- | --- | --- | --- |
| Записи нет | Впервые отправить идентификатор | 202 | Одна новая запись |
| Заявка в очереди, принадлежит клиенту | Отправить тот же идентификатор повторно | 204 | По-прежнему одна запись |

Обе части описывают одну версию сервера. Срок действия идентификатора в течение этой проверки не истекает.
