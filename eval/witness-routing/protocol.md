# Меняется ли время до проверенного исполняемого примера при замене модели построения

Сравниваются два маршрута. В обоих независимый смысловой аудит выполняет Astra. В одном правила предлагает Astra, в другом Sol. Обе модели получают одни и те же исходные строки, свидетельство и схему. Сначала фиксируются входные JSON, правила оценки и порядок запусков. Токены из кэша провайдера могут встречаться в обоих маршрутах. Локальные контрольные точки отключены.

| Сценарий | Мера успеха для заданного примера |
|---|---|
| BCC, месяц покупки | Февраль 0/4 000 ₸, контроль совпадает |
| BCC, изменили порог | За месяц пришло 1/2 уведомления, контроль совпадает |
| Депозит отеля | После клиринга разница 11 200 ₸ в пользовательском остатке или в величине оставшегося блока |
| Комиссия эквайринга | Комиссия в выписке 9/10 тиынов |
| API выписки | `AWAITING_SIGNATURE` и `MANUAL_REVIEW` на одном внешнем запросе, при двух других статусах подписи результаты совпадают |
| Исторический пример SDK | Отдельный трудный случай с областью применимости. Записываем точный сигнал и текст отказа. Гипотеза из комментария не доказывает второе реальное поведение сервера |

Для каждого из шести случаев два независимых раунда по двум маршрутам. Второй раунд проводится повторно через час с обратным порядком. Обе модели в одной паре запускаются параллельно, чтобы сравнивать их в близких условиях. При отказе или ошибке сохраняется первая попытка целиком. Отсутствие ответа по цели и неправильное утверждение различаются. Числа сопоставляются с исходником и программой, а в пяти основных случаях также проверяется метка наблюдаемого поля. Иная допустимая ситуация возможна и подлежит отдельному разбору.

Заранее выбранный порог изменения маршрута по умолчанию — все пять основных проверок пройдены в каждом раунде, новые ошибочные утверждения отсутствуют и медиана парных отношений времени Sol/Astra не выше 0,80 в каждом раунде. Сравнение оценивает только построение и аудит заданного замечания. Измерение включает исправленные попытки и ожидание провайдера. Оно не оценивает скорость анализа всего ТЗ и цену коммерческого API.
