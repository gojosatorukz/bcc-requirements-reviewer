# Питч «Разбор ТЗ»

[PDF для жюри](razbor-tz-pitch.pdf) · [PPTX со сценарием в заметках](razbor-tz-pitch.pptx) · [HTML-исходник](index.html) · [Бизнес-модель](../../docs/business-model.md)

14 слайдов на 4 минуты 30 секунд. На заключительном слайде — просьба к жюри и два QR-кода для перехода на сайт и в отчёт. Порядок: история → как мы пришли → пользователь и боль → как решаем (5 шагов, доказательство, уточнение) → проект коротко (архитектура, результат) → бизнес-модель (тарифы, экономика, рынок) → планы → просьба.

Стиль совпадает с сайтом: шрифт Rubik, оранжевый, жёлтый и кремовый, карточки с жёсткой тенью, помощница-маскот. Иллюстрации нарисованы векторами, фото не используются. Скриншоты в `img/` — реальный интерфейс продукта.

Пересобрать PDF из HTML можно в Chrome: откройте `index.html` → Печать → Сохранить как PDF, поля «Нет», фон включён.

## Быстрая пересборка после изменения данных

Тексты слайдов и заметок лежат в `build/deck.js` и `build/pptx.js`. Команда `presentation/pitch/build/build.sh` за минуту собирает HTML, PDF и PPTX и печатает хеши. Один раз перед первым запуском: `npm install`, затем `python3 -m venv .venv && .venv/bin/pip install pymupdf` в папке `build`. Каждая пересборка меняет хеши, поэтому после неё нужно обновить `runs/bcc-jury/materials.json` и пересобрать ZIP. Сборка демо-видео: `build/tts.py` (озвучка Gemini TTS) и `build/compose.py` (кадр, помощница, облачка).
