# Питч «Разбор ТЗ»

[PDF для жюри](razbor-tz-pitch.pdf) · [PPTX со сценарием в заметках](razbor-tz-pitch.pptx) · [HTML-исходник](index.html) · [Бизнес-модель](../../docs/business-model.md)

15 слайдов: 14 на 4 минуты 30 секунд и слайд «Вопросы?» с двумя QR. Порядок: история → как мы пришли → пользователь и боль → как решаем (5 шагов, доказательство, уточнение) → проект коротко (архитектура, результат) → бизнес-модель (тарифы, экономика, рынок) → планы → просьба.

Стиль совпадает с сайтом: шрифт Rubik, оранжевый, жёлтый и кремовый, карточки с жёсткой тенью, помощница-маскот. Иллюстрации нарисованы векторами, фото не используются. Скриншоты в `img/` — реальный интерфейс продукта.

Пересобрать PDF из HTML можно в Chrome: откройте `index.html` → Печать → Сохранить как PDF, поля «Нет», фон включён.
