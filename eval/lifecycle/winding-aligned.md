# Сменный план намотки

## Рабочее место мастера

Кабельный цех готовит несколько барабанов к отгрузке в одну смену. До физической намотки мастер комплектует каждый барабан из учтённых медных отрезков. Маршрутный лист служит заданием оператору участка.

Новый барабан создаётся как черновик. В черновике плановая длина может быть пустой. На этом этапе мастер назначает и меняет место на стеллаже. Пока мастер не включил комплектование, отрезки не поступают в план. На форме есть поля «Ячейка», «План, м», переключатель «Комплектовать» и кнопка «Записать». GET /drums/{drum}/layout возвращает ячейку, режим и план. Для пустого плана возвращается null.

| Операция | Передаваемые поля | Ответ |
| --- | --- | --- |
| PUT /drums/{drum}/layout | bin — непустой код ячейки, planned_m — целое от 6 до 240 либо null для черновика, picking — логическое значение. bin и picking обязательны. При picking=false значение planned_m может быть null, в том числе при первой записи только ячейки. При picking=true planned_m обязателен и должен лежать в указанном диапазоне. Форма передаёт пустой план как null при выключенном комплектовании и разрешает записать ячейку. | 200 с сохранённой раскладкой при корректных полях, 422 при нарушении схемы. |

## Ведомость комплектования

Каталог отдаёт длину отрезка целым числом миллиметров. Ведомость хранит точную сумму длин назначенных отрезков по барабану за смену. Команда «Снять отрезок» до намотки исключает его из плана и уменьшает эту сумму. Привязки снятого отрезка к барабану больше нет.

Изменение из терминала содержит ключ движения, барабан, смену, код отрезка и действие. Повторная доставка движения с тем же ключом не меняет состав ведомости второй раз.

## Выдача маршрутного листа

Когда сумма назначенных длин переходит со значения ниже плана на значение не ниже плана, цеховая система ставит маршрутный лист на выход через печатный шлюз. План в метрах переводится в миллиметры умножением на 1000, итог ведомости сравнивается без округления. На один барабан за одну смену выдаётся максимум один такой лист. Снятие отрезка после выдачи листа уменьшает ведомость и сохраняет отметку выдачи. Пока смена продолжается, новое достижение плана по этому барабану сохраняет прежний лист. Отметка учитывается по паре барабан и смена, выдача для другого барабана проверяет его собственную отметку.

Участок использует один сетевой шлюз для всех барабанов. В ведомости хранится отметка выдачи листа. Шлюз доступен отдельным вызовом и возвращает номер печатного задания после приёма. Терминал продолжает передавать движения после восстановления связи.

Вместе с движением, впервые достигающим плана, ведомость сохраняет задание на выдачу в одной транзакции. Идентификатор задания строится из барабана и смены. Шлюз с таким идентификатором печатает один маршрутный лист и для дальнейших запросов возвращает прежний номер. При потере подтверждения служба повторяет запрос с тем же идентификатором до получения номера и затем записывает его в ведомость.
