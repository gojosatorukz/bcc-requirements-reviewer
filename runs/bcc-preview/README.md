# Предварительная проверка документа BCC-HUB

[Исходная спецификация организаторов](https://github.com/BCC-HUB/ai-requirements-validator-task/blob/928c1aa364265426105b69ba7a3444eac11b22db/docs/requirements.md) считана из коммита `928c1aa`. Git blob скачанного файла совпал с опубликованным `9945b9c22e5a43e32e3956c792d0361c46e49167`. Корневой документ хакатона требует также реестр требований, оценку каждого пункта, анализ всего набора и вывод о готовности. Здесь проверен один компонент — поведенческие противоречия.

## Первый проход

В [автоматически созданном JSON](conflicts.json) шесть кандидатов. Запуск занял 47,46 с. Каждая пара цитат совпала с указанными строками. Агент получил только текст документа и общую инструкцию.

| № в JSON | Краткий итог ручного чтения |
|---|---|
| 1 | Ф-2 и пример приёмки дают разные месяцы для одной проведённой покупки. Обе стороны явно выражены. |
| 2 | При том же месяце и той же карте правила расходятся по разрешению второго push после повышения порога. |
| 3 | Чтение и сохранение смешаны в описании метода. Вопрос к владельцу API уместен. Отдельно нужно проверять полноту контракта чтения. |
| 4 | Пример ошибки суммы в разделе 200 и общее правило 400 создают вопрос о коде при 999 ₸. Строку JSON нужно читать под заголовком статуса. |
| 5 | Прежнее состояние можно понимать как возвращаемые поля либо как сохранённое состояние сервиса. Нужна явная спецификация тела ответа. |
| 6 | Специальное правило для чужой карты может уточнять общую политику 403. Безусловная классификация этой пары как конфликта завысила бы уверенность. Сохраняется редакционная проблема в заголовке раздела. |

Цитаты подтверждают происхождение текста. Одного совпадения цитат недостаточно для решения о совместимости требований. Количество кандидатов не следует использовать как измеренное количество ошибок в документе.

## Попытка согласовать правила

[Отдельная сессия Astra](second-opinion.json) получила весь исходный текст и шесть кандидатов. Ей поручено найти лучшее согласованное прочтение и подкрепить вердикт цитатами. За 36,89 с получены четыре оценки «конфликт» (1, 2, 4, 5), одна «требует уточнения» (3) и одна «совместимо» (6). Проверены номера всех шести кандидатов, ссылки на текст и хеш родительского отчёта.

Во втором проходе специальный 404 для чужой карты согласован с общим 403. Для чтения настроек выявлен недостающий контракт. В пункте 5 остаётся расхождение с ручным ревью: модель прочитала «вернуть прежнее состояние» как обязанность включить старые значения в тело ответа. Степень однозначности этой фразы стоит уточнить у владельца API. Второе мнение использует ту же модель и не является независимой экспертной разметкой. Четыре модельных вердикта нельзя представлять жюри как четыре доказанных дефекта.
