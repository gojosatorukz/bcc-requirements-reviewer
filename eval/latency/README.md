Сравниваем один официальный документ BCC и две версии спецификации планетария при одинаковых входных байтах, модели и числе исполнителей в каждой паре. Все шесть запусков завершились без полного JSON. В первой волне проверялись три документа в одном временном окне. Во второй волне планетарии запускались последовательно с новыми пустыми каталогами. Время отдельных стадий заметно менялось: пакет 19–59 согласованного планетария прошёл за 72,84 с во второй волне; пакет BCC 81–106 в первой волне прошёл за 303,53 с. На слепом планетарии сохранились обе реальные группы анализа полей второй волны. Во всех 15 сочетаниях поле, операция и статус совпали с заранее записанным эталоном, в том числе в двух нерешённых ветвях POST. Связей с одноимённым полем чужой операции нет. Агент сформировал точный вопрос внутри стадии. Доставка этого вопроса в итоговую карточку такого прогона не подтверждена. У BCC независимо проверена сохранённая группа полей ошибок.
