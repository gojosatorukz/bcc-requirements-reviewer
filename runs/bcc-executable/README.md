# Официальный прогон BCC с исполняемыми примерами

[PDF](review.pdf) · [Автономный HTML](review.html) · [Исходный JSON](review.json) · [Документ организаторов](https://github.com/BCC-HUB/ai-requirements-validator-task/blob/928c1aa364265426105b69ba7a3444eac11b22db/docs/requirements.md)

Полное ревью выполнено в чистом клоне `e35f768538ef` командой `python3 -m reviewer` с четырьмя исполнителями. За 366,51 с сделано 13 свежих обращений к GPT-6.2 Astra. Одна попытка построить модель второго конфликта отклонена из-за несовместимых единиц измерения. Сохранённый JSON содержит исходные данные модели, перепроверенные цитаты и результаты интерпретатора. От него получены HTML и PDF.

| Замечание | Что увидит клиент | Где уточнить правило |
|---|---|---|
| D-01 | На февральском счётчике 0 или 4 000 ₸. При покупке в полночь и проведении через три минуты обе трактовки дают 4 000 ₸. | Сверить правило месяца в строке 38 с приёмкой в строке 64. Ответ владельца нужен для пересечения границы месяца. |
| D-02 | После повторного пересечения повышенного порога за месяц придёт одно или два уведомления. Если новый порог выше накопленного на один тенге, останется одно. | Согласовать приоритет месячного ограничения из строки 39 и условия новой настройки в строке 40. |

198 строк, 138 блоков, 105 записей реестра, 6 синтаксически корректных примеров JSON. Восемь нарушений и восемь открытых вопросов. Для разработки и тестирования вынесены отдельные решения «можно частично». Полнота относительно независимой экспертной разметки всех требований пока не измерена.

SHA-256 оригинального ТЗ — `e7dae55e5453a250d93e335f5ff9c7f775f4457ccddd333f4a67e47b20d74381`. Команды для проверки файла и воспроизведения расчётов приведены в [корневом README](../../README.md). [Протокол независимых испытаний](../../eval/executable/README.md)

Для защиты доступны [два хода владельца](owner/dialogue.html), [ошибочная редакция после согласования](owner/wrong-revision.html) и [их запись в рабочем месте на том же снимке Git](https://github.com/gojosatorukz/bcc-requirements-reviewer/blob/1f4ae24/presentation/bcc-demo.mp4). Они привязаны к JSON этого прогона. При воспроизведении отчёта без модели можно проверить цитаты, вычисления и ход согласования. Новый ответ владельца передаётся модели.

Для текущей подачи зафиксирован [новый полный прогон с проверкой области применения](../bcc-release/README.md).
