# Довопрос по API и по согласованию документа

Оба замечания взяты из [отчёта по официальному ТЗ](../../../runs/bcc-submission/review.json). Реплики владельца смоделированы. GPT-6.2 Astra обработала их через обычный провайдер приложения. В паспортах ходов сохранены хеши движка и базы. У этих двух дополнительных испытаний в рабочем дереве параллельно менялся интерфейс. Основной эксперимент D-01 выполнялся в отдельных чистых клонах.

**D-08. Чтение настроек карты.** В Chrome аналитик выбрал D-08 и указал метод и результат для сохранённой настройки. Агент сохранил эту часть и спросил, какой запрос выполняется и что вернёт API при первом открытии карты demo-42. После перезагрузки страницы на экране остался тот же вопрос. Владелец определил ответ для первого открытия и указал, что запись создавать не нужно. Повторная проверка исходного ТЗ оставила замечание открытым. JSON обоих ходов отдельно скачан с сервера и сверен с записью обсуждения. [Экран после первого ответа](d08-follow-up.png) · [Обе реплики и правило](d08-dialogue.json)

**D-16. Версия и статус ревью.** В первом прогоне агент записал ожидание письма от согласующих как ещё одно условие будущей редакции. После уточнения инструкции повторный реальный прогон сохранил версию и дату, спросил только о статусе и принял ответ «на согласовании». В итоговой формулировке остались два проверяемых условия.
