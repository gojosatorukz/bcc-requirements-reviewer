# Два способа запустить один и тот же анализ

На 27 ноября 2026 года для официального отчёта выбран GPT-6.2 Astra. В таблице приведены результаты конкретных запусков. Количество замечаний само по себе не определяет качество. Существенное различие здесь — воспроизводимость конфликта и точность вопроса для приёмки.

| Вход и модель | Результат |
|---|---|
| Официальное BCC, Astra через Codex | 104 записи и 17 итоговых замечаний. У месяца покупки и повторного push есть две исполняемые трактовки и соседние контроли. В D-15 есть отдельный вопрос о поле `result` в ошибочном ответе. [Паспорт](../../runs/bcc-release/README.md) |
| Тот же официальный документ, Gemini 3.5 Flash-Lite через API | 50 записей и 2 итоговых замечания. Проверка поля `result` попала в секцию анализа контракта, но вопрос об обязательности поля отсутствует в итоговых замечаниях. Единственный кандидат на исполняемый пример вернул `provider_unavailable`. [Сырой отчёт](bcc-flash-lite.json) |
| Перевод, новый документ о 15 и 30 минутах, Gemini 3.5 Flash-Lite | 23,13 с, 5 новых вызовов. Найден конфликт. Агент спросил, через сколько минут снимать резерв. На шаге построения примера модель потребовала предварительного решения владельца, поэтому расчёт не подтверждён. [Тестовое ТЗ](transfer.md) · [Отчёт](transfer-flash-lite.json) |

Официальный тест Flash-Lite прервался при ответе API HTTP 503. Повторный запуск с тем же каталогом контрольных точек завершился. Его паспорт содержит 4 новых обращения и 13 восстановленных попыток. Указанные в нём 24,36 секунды относятся к возобновлению проверки. У обоих провайдеров SHA-256 исходного официального документа совпадает.

Отдельно в браузере проверена помощница с реальным Gemini API. По загруженному отчёту перевода она назвала сроки 15 и 30 минут и дала две ссылки на основания в текущем документе.

## Повторить

Настройте профиль Gemini по [README](../../README.md). Из корня проекта выполните команду с одним параллельным обработчиком.

```sh
python -m reviewer eval/gemini/transfer.md output/transfer.json --workers 1 --checkpoint-dir output/cache-transfer
python -m reviewer.render output/transfer.json output/transfer.html
```
