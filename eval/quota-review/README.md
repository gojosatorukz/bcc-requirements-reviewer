# Ревью при исчерпанной квоте

Новый документ для испытания — [бронирование спектрометра](reservations.md). До изменения ядра зафиксированы три ожидания.

- Строки 7 и 8 задают одинаковые калибровку и срочность. Вопрос должен назвать смены A и B. Строка 9 относится к другой срочности.
- В строке 13 вместо срока удержания стоит TBD. Нужен вопрос о конкретном сроке.
- В строке 18 лишняя запятая в JSON. Вопрос должен вести к исправлению образца.

Контрольная редакция удаляет второе решение для совпадающих входов, задаёт срок 20 минут и исправляет запятую. Эти замечания должны исчезнуть. Молчание локальных правил само по себе не подтверждает готовность документа к разработке.

## Реальный результат на Render

27 ноября 2026 года до обновления полный запуск завершился сообщением о лимите. Отдельная кнопка структуры нашла ошибку JSON в строке 18, скачать отчёт из полного запуска было невозможно. [Что увидел посетитель](before-site.json)

В 22:11 по Астане после публикации тот же файл с тем же SHA-256 дал три вопроса. Браузер открыл HTML, перешёл по цитате к строке 8 и скачал JSON. В отдельной сессии контрольная редакция дала ноль замечаний по этим правилам. Оба частичных отчёта выпущены после настоящего отказа Gemini по квоте.
