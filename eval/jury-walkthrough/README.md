# Приёмка глазами нового пользователя

До первого запроса зафиксирован новый синтетический документ о бронировании музыкальных залов. Он проверяет две независимые проблемы. Правило направляет 18 музыкантов в Малый зал, строка приёмки отправляет ту же группу в Большой. Для 17 и 19 человек обе трактовки согласны. Вопрос владельцу должен позволить выбрать зал для группы ровно из 18 человек.

Описание успешного ответа требует номер заявки и зал, а пример содержит только номер. Точное имя поля для зала в ТЗ отсутствует. Отчёт может запросить имя и обязательность поля либо исправленный пример. Ссылка на исходную строку позволяет проверить вывод. Полный прогон и частичный разбор при исчерпанной квоте оцениваются отдельно. [Входной документ](rehearsal.md)

Для каждой публичной загрузки использовали отдельную чистую сессию Chrome с экраном 390 × 844. На главной открыли сохранённый банковский расчёт, затем загрузили файл и нажали «Запустить проверку». Оба POST вернули HTTP 202, ссылки на HTML и JSON открылись, ошибок JavaScript и горизонтальной прокрутки на главной не обнаружено. Время приведено для одного наблюдения каждой редакции. Ноль в контрольном документе означает отсутствие находок в пределах выполненных локальных проверок.

## Запуск по README из чистой копии

Через HTTPS с доступом на чтение клонировали GitHub, создали отдельное окружение Python 3.12.14 и выполнили `python -m pip install -r requirements.txt`. Оригинал BCC скачали по закреплённой ссылке из README. В клоне `0ca9de2` исходная команда с действующим ключом при HTTP 429 завершилась кодом 1, файл результата отсутствовал. С `--partial-on-quota` тот же CLI сохранил HTML за 0,95 с и вернул код 0. Сохранённый официальный отчёт Astra прошёл отдельную сверку SHA исходника и повтор обоих расчётов без ключа.

Для версии `823d86a` скачали ещё один чистый HTTPS-клон и повторили установку. Обновлённая команда CLI с ключом Gemini при фактической квоте дала два вопроса на исходном ТЗ за 1,03 с и ноль на исправленном за 1,47 с. Затем удалили локальную конфигурацию ключа и проверили кнопку «Проверить через сервер проекта» из браузера локальной копии. Для обоих документов HTML открылся, а содержание скачанных JSON совпало с соответствующими отчётами прямой загрузки на публичный сайт.
