# Word-спецификация банковского перевода

Учебное ТЗ написано для проверки ввода DOCX. В исходном [файле](transfer.docx) общая фраза задаёт комиссию 200 ₸ при сумме от 10 000 ₸ включительно, а таблица приёмки оставляет комиссию нулевой ровно при 10 000 ₸. Для 9 999 и 10 001 результаты согласуются. В [исправленной версии](corrected.docx) изменена только комиссия в строке таблицы. Оба документа содержат обычные абзацы Word, настоящую таблицу и тело API с явной подписью JSON. Ответ не помещается в промпт агента.
