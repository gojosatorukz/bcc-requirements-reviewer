# Контроль до запуска моделей

Авторская пара документов для инженерного испытания. Обоим вариантам передаются только исходник и общие инструкции. Здесь заранее записаны ожидаемые результаты.

| Контроль | Исходная версия | Исправленная версия |
|---|---|---|
| 7, 15 · первый запрос ровно в 16:00:00 без блокировки | Два несовместимых состояния CANCELLED и QUEUED, критический дефект, вопрос владельцу | Принятая отмена, конфликт закрыт |
| 25–29 · пример удачного ответа | Завершающая запятая делает пример синтаксически недопустимым JSON | Синтаксически корректный JSON |
| 14, 16 · секунда до и после | Оба примера согласованы с регламентом | Оба согласованы |
| 8, 17 · ручная блокировка | Явное исключение, отдельного конфликта нет | Исключение сохраняется |

Для сравнения ищем замечания одним сильным запросом к той же модели, с полным текстом, общими критериями, требованием точных цитат и той же шкалой критичности. Отдельно выполняем полное ревью. Однопроходный вариант выдаёт только замечания. Полный вариант дополнительно строит реестр, проверяет покрытие, сверяет кандидатов и выдаёт решение о готовности. Длительности отражают эти разные объёмы работы. Первые полные ответы сохраняются. Качество сравниваем на общих контролях, дополнительные находки рассматриваем отдельно. Синтетический тест не измеряет эффект для пользователей банка.
