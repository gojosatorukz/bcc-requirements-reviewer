Как решаем

От файла ТЗ до решения владельца за 5 шагов

1
Читает
PDF, DOCX, MD, TXT. Таблицы и JSON-примеры API
2
Нарезает
ID отчёта, ID документа (Ф-1…) и дословная цитата
3
Проверяет
Каждое требование и весь набор по выбранным критериям ISO/IEC/IEEE 29148 и IEEE 830
4
Доказывает
Две программы правил на одном примере + контроль
5
Спрашивает
Вопрос владельцу, затем перепроверка новой редакции
Код проверяет привязку каждой цитаты к строке и пересчитывает поддерживаемые примеры. Верность трактовки подтверждает владелец. Отчёт: паспорт, нарезка, проверка каждого требования и набора, сводка, итог.

Как решаем · доказательство

Не мнение модели, а расчёт, который можно повторить

1
Один вход, два итога
Правило А, строка 38 → 0 ₸. Правило Б, строка 64 → 4 000 ₸
2
Контрольный пример
Покупку совершили и провели внутри одного месяца: оба правила дают 4 000 ₸. Спор только о стыке месяцев
3
Повторит любой
Команда replay пересчитывает пример без модели и ключа
Тем же методом найден второй конфликт: Ф-3 и Ф-4 дают 1 или 2 push за месяц после смены порога

Проект коротко · архитектура

LLM рассуждает, код проверяет

Вход
PDF / DOCX / MD / TXT → строки, таблицы с заголовками, JSON-примеры
Сегментация
Блоки с адресом строки, роль блока, исходные ID
LLM · блоки
Параллельно до 8 воркеров: реестр и оценка каждого требования
LLM · весь набор
Сверка правил, примеров и API: полнота, согласованность
Валидатор · код
Каждая цитата и номер строки сверяются с исходником. Невалидный ответ модели отклоняется
Witness VM · код
Две трактовки правила исполняются на одном входе и на контрольном. Разные итоги = конфликт
Приоритет и перепроверка
Критичность по версионной шкале. Адресная перепроверка новой редакции
Выход
JSON → HTML / PDF на русском · веб-интерфейс · экспорт задач в Jira (CSV) · паспорт с коммитом и SHA-256
Провайдеры
Адаптеры Codex CLI (GPT-6.2 Astra), Gemini и Cloudflare Workers AI · при лимите квоты частичный отчёт
261 проверка: 247 Python и 14 JS, включая 4 сквозных сценария в Chrome · запуск одной командой: python -m reviewer req.pdf report.html
