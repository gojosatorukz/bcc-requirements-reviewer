# Экспорт субтитров прямого эфира

Доступные языковые дорожки: English, Deutsch, Español.
После окончания эфира редактор экспортирует один файл субтитров.
В метаданные файла записывается язык, выбранный при открытии эфира. Редактор может затем сменить дорожку, начальный выбор для метаданных сохраняется.
Инструкция экспортёра: в поле track файла запишите язык последней активной дорожки на момент окончания эфира, включая переключения редактора.

Для проверки открывают эфир на Deutsch, переключают на Español и завершают эфир. Проверяют поле track выгруженного файла.
Во втором прогоне весь эфир идёт на English. Обе инструкции дают track равный English.
