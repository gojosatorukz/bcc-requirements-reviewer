# Планетарий. Проверка субтитров перед показом

Редактор готовит субтитры к купольной программе. На одном экране можно запустить пробный просмотр субтитров сцены и отдельно проверить её готовность к показу. Клиент разбирает ответ каждой операции по её собственному контракту.

## POST /scenes/{scene}/proofs

Сцена существует и видна редактору. Тело запроса содержит текст дорожки субтитров. Если дорожка принята, редактор переходит к ожиданию пробного просмотра. Если сцена занята монтажёром, запрос не ставится в очередь. Ошибка временных меток дорожки также предотвращает постановку. При отсутствии свободного вычислителя редактору показывается время до следующей попытки. Эти четыре ответа исчерпывают исходы данного сценария.

| Ключ тела ответа | Тип | Назначение |
| --- | --- | --- |
| nextStep | string | Код дальнейшего действия в интерфейсе редактора |
| proofRef | string | Номер поставленного на расчёт пробного просмотра |
| hint | string | Текст пояснения для редактора |
| cooldownSec | integer | Интервал ожидания в секундах |

При принятии сервер отвечает 202. В каждом таком ответе есть nextStep со значением WAIT_PROOF и непустой proofRef. При конфликте с монтажом сервер отвечает 409. Неверные временные метки дают 422, в его теле всегда есть nextStep со значением FIX_TIMING. При отсутствии свободного вычислителя сервер отвечает 503.
Во всех трёх ошибочных ответах обязателен hint и отсутствует proofRef. В ответе 202 ключ hint отсутствует. Ключ cooldownSec обязателен при 503 и отсутствует во всех остальных ответах.

### HTTP 202. Просмотр принят

```json
{"nextStep":"WAIT_PROOF","proofRef":"KP-71"}
```

### HTTP 409. Идёт монтаж

```json
{"hint":"Сцена открыта у монтажёра"}
```

### HTTP 422. Ошибка дорожки

```json
{"nextStep":"FIX_TIMING","hint":"Конец реплики раньше начала"}
```

### HTTP 503. Расчёт будет доступен позже

```json
{"hint":"Все вычислители заняты","cooldownSec":17,"nextStep":"RETRY_LATER"}
```

## GET /scenes/{scene}/screen-check

Кнопка «Проверить показ» только читает готовность этой же сцены. Код 200 означает, что сцена выведена на купол, код 409 — что в данный момент сцену редактируют. Ни запросы пробного просмотра, ни очередь вычислителей в этой операции не используются.

Поля тела перечислены здесь исчерпывающе. В каждом 200 возвращаются ровно nextStep со значением GO_LIVE и domeLabel с названием купола. В каждом 409 возвращаются ровно nextStep со значением ASK_PROJECTIONIST и deskNote с номером монтажного места.

### HTTP 200. Купол готов

```json
{"nextStep":"GO_LIVE","domeLabel":"Восточный купол"}
```

### HTTP 409. Купол на монтаже

```json
{"nextStep":"ASK_PROJECTIONIST","deskNote":"Пост 4"}
```
