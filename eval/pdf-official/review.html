Тестирование

Можно частично

Можно подготовить проверки граничных сумм, перевода, дубликата события, минутного срока передачи и одинакового статуса для чужой и отсутствующей карты. Для положительного теста на достижение порога можно явно задать включённую настройку и отсутствие предыдущей отправки. Полную приёмку блокируют несовместимые ожидания по месяцу и второму push, неопределённые контракты экрана и API и отсутствие измеримого критерия доставки клиенту. Пустой подраздел для тестировщиков сам по себе не мешает начать эту работу.

D-03 · открытый вопрос · существенный

Срок получения push клиентом не связан со сроком передачи на отправку
