# Выдача тубуса в студии печати
Студия выдаёт готовый тубус у одного из двух окон. Варианты окна — северное и южное.
При первом чтении кода талон навсегда получает исходное окно. После переноса тубуса указатель клиента сохраняет окно первого чтения.
| Событие | Что показывает указатель клиенту |
| --- | --- |
| Сотрудник переносит тубус в другое окно до выдачи | Немедленно заменить указанное окно новым местом тубуса |
Приёмка: код впервые прочитан у северного окна, затем до выдачи тубус перенесли к южному. Клиент открывает указатель.
Контроль: если тубус остался у северного окна, указатель показывает северное.
